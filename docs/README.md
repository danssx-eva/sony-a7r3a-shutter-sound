## 教程

**动手之前先做备份。** ILCE-7RM3A 没有官方固件包，相机上的原厂内容一旦被覆盖就找不回来。
[教程 01](教程/01-备份与读取固件.md) 就是这一步，不要跳过。

按顺序做，每篇包含原理和步骤。

| 教程 | 内容 | 风险 |
|---|---|---|
| [01 备份与读取固件](教程/01-备份与读取固件.md) | **动手前必做**：完整的原厂备份 | 无，纯只读 |
| [02 找到播放通道](教程/02-找到播放通道.md) | 怎么让相机发声（IPC 消息格式） | 无，纯分析 |
| [03 找到触发点](教程/03-找到触发点.md) | 钩哪个位置，为什么 | 无，纯分析 |
| [04 编写载荷](教程/04-编写载荷.md) | 240 字节载荷的每条指令和六条铁律 | 无，离线完成 |
| [05 打钩子](教程/05-打钩子.md) | 4 字节跳转，内存注入 | 低，重启即恢复 |
| [06 持久化到闪存](教程/06-持久化到闪存.md) | 写两个 1 KB 块，冷启动验证 | 高，写坏可能起不来 |
| [07 替换音效](教程/07-替换音效.md) | 音效格式、槽位选择、部署 | 低，备份后可控 |
| [08 调整音量](教程/08-调整音量.md) | Backup 属性的读写 | 低 |
| [09 连拍支持](教程/09-连拍支持.md) | 为什么一个钩子自动覆盖连拍 | 无 |

前六篇是注入方案（让电子快门出声），后三篇是配套（换成自己的声音、调响、连拍）。

## 最小路径

只想换声音，不碰注入：

```
01-固件介绍（了解环境）
→ 教程/01-备份与读取固件（备份原厂音效）
→ 教程/07-替换音效（换成自己的）
→ 教程/08-调整音量（调响）
```

想让电子快门出声：

```
01-固件介绍
→ 02-依赖与环境（配好环境）
→ 教程/01 到 06 顺序做
→ 教程/07-09（可选，换声音、调响、连拍自动支持）
```
