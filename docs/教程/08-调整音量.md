# 教程 08 · 调整音量

## 结论

音量存在 Backup 属性里，**每个 soundId 一个字节，范围 0..7**。

| soundId | 主通道 BKID | 副通道 BKID | 项目里设为 |
|---|---|---|---|
| 0x04 FOCUSLOCK | `0x002B0022` | `0x002B0061` | 2（本项目已还原） |
| 0x07 CAUTION | `0x002B0020` | `0x002B0059` | 7 |

本项目用 0x07 CAUTION，主通道 `0x002B0020` 设为 7。

## 只调自己替换的那一路

音量按 soundId 独立存储。改错 soundId 会影响对应的原生提示音。

**本项目踩过的坑**：早期为了试 `0x04 FORCUSLOCK` 槽位，把它主副通道音量都从 2 拉到 7。
后来改用 `0x07 CAUTION`，忘了改回去，结果对焦提示音和快门声一样响。
**这个错误后来已经修正：0x04 的主副通道都还原成了 2。**

规则：**换哪个槽位，只调那个槽位。改完把 slot、BKID、原值记下来。**

## 命令

```bash
# 读
python tools/camera/a7r3a_prop.py --read --id 0x002b0020

# 写（第一个参数带 0x，第二个是纯十六进制、不带 0x）
python tools/camera/a7r3a_prop.py --write 0x002b0020 07 --go
```

## BKID 怎么算

主通道：

```
BKID = 0x2B008B - delta1[soundId]
```

`delta1` 是固件里的一张静态表，按 soundId 索引。确认过的几个：

| soundId | delta1 | BKID |
|---|---|---|
| 0x04 | 0x69 | 0x002B0022 |
| 0x07 | 0x6B | 0x002B0020 |

副通道用 `delta2` 表，算法相同。

**不要自己推公式。** 这张表是从固件里读出来的常量，不是线性的。要用别的 soundId
就自己去 dump 那张表。

## 三套"音量"不能混

反汇编里有三处看起来都像"音量"的东西，实际是三套不同的刻度：

| 出处 | 刻度 | 是否可调 |
|---|---|---|
| Backup 属性字节 | 0..7 | 是，本项目用这个 |
| `ObjSpeaker::ExecCmdSetVol` 参数 `0x1002` | 1..16 | 可能更响，未验证 |
| RTOS 侧内部音量 | 未知 | 不可从 Linux 侧触及 |

`0x1002` 那条路线没试过。如果 Backup 的 7 还不够响，这里是下一个候选，见
`../附录/死路清单.md`。

## 改完要重启

音量在上电时从 Backup 读进内存，改属性之后当前这次开机不会生效。

```
改属性 → 拔电池 → 装回开机 → 生效
```

和换音效一样需要冷启动。

## 音量是主，处理链是辅

Backup 音量 0..7 是主要的响度手段，改一档听感变化很明显。想更响先设 7。

处理链只改变动态和音色，不能替代音量。`examples/convert_audio.py` 默认开启：

```
峰值归一化
→ 高频提升 y[i] = x[i] + 0.8*(x[i] - x[i-1])
→ 动态压缩（阈值 0.20，比率 4:1）
→ tanh 软限幅（系数 1.15）
→ 缩放到峰值 32000
```

在合成测试音上，这套链把 RMS 从约 2380 提到约 3740（约 +4 dB）；实际效果取决于素材，
不会像音量 2→7 那么明显。不想要处理加 `--no-loudness`。

处理代码在 `examples/convert_audio.py`。

## 副通道要不要改

主通道通常够用。副通道影响的是另一路混音，改了可能连带影响其他提示音的行为。

本项目只改主通道。
