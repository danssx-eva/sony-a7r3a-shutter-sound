# 02 · 依赖与环境

## 你需要一台能进服务模式的相机

```
· Sony ILCE-7RM3A，固件 1.00，非国行
· USB 数据线（原装或能传数据的）
· Windows / macOS / Linux 都行，本文以 Windows 为例
```

**国行、其他固件版本、其他机型都没有验证过。**

## 软件依赖

### 必装

| 组件 | 版本 | 用途 |
|---|---|---|
| Python | 3.10 以上 | 所有脚本 |
| Sony-PMCA-RE | `vendor/` 副本 | USB 通信、服务模式切换、相机 shell |
| libusb-win32 驱动 | — | Windows 下访问服务模式 |

### Python 库

```bash
pip install -r requirements.txt
```

分三组，只做离线分析可以跳过第二组：

**A 必需**

| 库 | 用途 |
|---|---|
| `capstone` | 反汇编 ARM |
| `keystone-engine` | 汇编 ARM（生成载荷） |
| `unicorn` | CPU 仿真（载荷离线自检） |
| `pyelftools` | 解析 ELF |

**B 连相机时才需要**

| 库 | 用途 |
|---|---|
| `pyusb` / `libusb-package` | USB 访问 |
| `asn1crypto` / `pycryptodomex` / `certifi` / `tlslite-ng` | PMCA 的认证与 TLS |
| `axmlparserpy` / `pyyaml` / `pycparser` | PMCA 的应用安装与配置 |
| `comtypes` / `pywin32` | PMCA 在 Windows 上的部分功能 |

`vendor/Sony-PMCA-RE/` 是原样副本。它的 `imports` 不会随本仓库的清单自动安装，
所以上面第二组是**手动列出来的**。只装 A 组的话，`tools/camera/` 下的脚本会在
导入 `pmca` 时失败（典型报错 `ModuleNotFoundError: No module named 'axmlparserpy'`）。

判断当前环境缺什么：

```bash
python -c "import importlib.util as u; [print(m, bool(u.find_spec(m))) for m in ('capstone','keystone','unicorn','elftools','usb','asn1crypto','axmlparserpy')]"
```

**C 可选**

`numpy` / `scipy` 只在写自定义音频处理链时需要，`examples/convert_audio.py` 本身
只用标准库。`ffmpeg` 是命令行工具，不是 Python 库。


### Windows 驱动（Zadig）

普通模式和服务模式是两个 USB 设备，各装一次驱动。

1. 相机切到要用的模式（普通 `054C:0D99` / 服务 `054C:0336`）。
2. 打开 Zadig → Options → List All Devices。
3. 选中相机条目，目标驱动选 `libusb-win32`，点 Replace Driver。
4. 另一个模式重复一次。
5. 装完后 Windows 资源管理器不再把相机显示成磁盘。拷照片用读卡器。
6. 要恢复成普通 USB 设备：设备管理器 → 右键相机 → 卸载设备 → 重新插拔；
   或“更新驱动程序 → 自动搜索”。

驱动只影响 Windows 访问方式，不改相机固件。

### 连接报错

```
GenericUsbException
RuntimeError: 未找到服务模式设备 0x0336
usb.core.USBError: [_usb_reap_async] reaping request failed
```

这是 USB 抖动，不是代码问题。应对：

1. 清掉残留的 python 进程（会占着 USB 句柄）
2. 操作之间等 4–6 秒
3. 大文件分段传：`camera.readFile` 拉文件每段 ≤2048 字节，`camera.writeFile`
   单次 ≤4096 字节（超过约 28 KB 会失败）
4. 关键操作读回验证，不要只看返回码
5. 反复失败就拔插相机，切一次普通模式再切服务模式

详见[踩过的坑](附录/踩过的坑.md)第二节。

### 相机卡住

只能拔电池。等十几秒再装回。

### 相机上的 busybox

相机上的 busybox 是 1.29.3。**准确的 applet 列表以相机上 `busybox --list` 的输出为准**，
不同固件版本的集合可能不同。

本项目自己的相机端脚本和教程里用到这些（都用 `busybox <cmd>` 的完整形式，不依赖 PATH）：

```
cat  ps  ls  dd  xxd  md5sum  sha256sum  cmp  cp  rm  mkdir  chmod
mount  sync  fsync  sed  grep  tail  cut  wc  head
```

写相机端脚本前先确认：

```sh
busybox --list | busybox grep -x 'fsync'
```

没有输出就说明这个版本不带该 applet，需要换写法。
